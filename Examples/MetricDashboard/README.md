# Metric Dashboard example

This presentation worker requires `example.metrics`, subscribes only while its
panel is visible, receives typed snapshot notifications, and publishes a value
for the host-owned native row. Install it together with Metric Provider to see
service routing and demand aggregation without either module knowing the other
module's process identity.

Its module name, summary and row title also demonstrate host-resolved English,
Simplified Chinese and Traditional Chinese module resources.
